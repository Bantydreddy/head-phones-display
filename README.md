# HeadZone Landing Page

A responsive product landing page for a fictional pair of wireless headphones, built with plain HTML, CSS and JavaScript (no frameworks).

## Features

- Hero section whose background colour follows the headphones on show (orange, grey, green). It cycles every 5 seconds, or you can pick a colour with the swatches
- Product lineup, features and reviews sections
- Waitlist signup form with email validation
- Responsive layout from phone to desktop
- Keyboard focus styles, image alt text, and reduced-motion support
- Images compressed to WebP (about 130 KB each instead of 2.5 MB)

## Project structure

```
index.html
css/style.css
js/main.js
images/   orange.webp, grey.webp, green.webp
```

## Run it

Open `index.html` in your browser. No build step needed.
